# Code of conduct

The rish-mcp community is expected to be respectful, constructive, and safe
for people of every background and experience level.

## Expected behavior

- Discuss ideas and code without attacking the person proposing them.
- Give actionable feedback and assume good faith while evidence is incomplete.
- Respect privacy. Never publish another person's tokens, device information,
  private relay URLs, or security reports.
- Accept moderation decisions and stop an interaction when asked.

Harassment, threats, discrimination, sexualized attention, doxxing, deliberate
disruption, and repeated unwanted contact are not acceptable in repository
issues, pull requests, discussions, or other project spaces.

## Enforcement

Maintainers may edit or remove content, lock conversations, reject
contributions, or temporarily or permanently restrict participation when this
policy is violated. Decisions should consider context, impact, and repeated
behavior, and should protect affected people from retaliation.

Do not post a sensitive conduct report publicly. Use GitHub's private reporting
and abuse-reporting tools or a private contact method listed on the repository
owner's GitHub profile. Security vulnerabilities follow
[`SECURITY.md`](SECURITY.md), not the conduct-reporting path.
